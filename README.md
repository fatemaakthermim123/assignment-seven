🛒 বাজার দর | BazarDor
Know today's market price before you step out of the house.


📖 About The Project

BazarDor (বাজার দর) is a web application that shows the daily prices of essential grocery items across different markets in Bangladesh. Users can browse products by category, sort them by price, and sign in to view detailed market-wise price information, including the lowest, highest and average price of every product.

🧰 Technologies Used
Technology	Purpose
⚡ Next.js:	React framework for routing, server components and route protection
🎨 Tailwind CSS:	Utility-first styling
🌼 DaisyUI:	Ready-made UI components built on Tailwind
🔔 React Toastify:	Success and error toast notifications
🔐 Better Auth:	Email/password, Google and GitHub authentication with MongoDB





✨ Key Features
1.📈 Live Price Marquee A scrolling ticker on the home page showing today's price and the price change (🔺/🔻 %) of every product.

2.🗂️ Category Browsing & Sort Dropdown Filter products by category and sort by price (Default, Low to High, High to Low) with correct handling of Bengali numerals.

3.🔍 Product Details Page Today's price, lowest, highest and average price, plus a market-wise price table for each product.

4.🔑 Authentication Sign up and sign in with email and password, or continue with Google and GitHub.

5.🛡️ Protected Routes & Profile Update The product details page is available only to logged-in users, and users can update their information from the My Profile page.
